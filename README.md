# Life Hub Dark

Quero criar um aplicativo chamado Gerenciador de Vida, para usar no meu celular Android.



O objetivo é reunir tudo em um só lugar: controle financeiro, organização da rotina, tarefas, hábitos, treinos e objetivos pessoais.



Quero um visual moderno, bonito e organizado, com tema escuro, detalhes em verde-água e textos fáceis de ler.



Na tela inicial, quero ver um resumo do meu dia, minhas tarefas, meus hábitos e minha situação financeira.



O aplicativo deve permitir cadastrar receitas, despesas, contas a pagar, dívidas, tarefas, hábitos, treinos e metas, com dados salvos mesmo quando eu fechar o aplicativo.



Quero começar com uma versão simples e funcional, priorizando opções gratuitas. Os dados devem ficar salvos no próprio aparelho, com possibilidade de fazer backup e restaurar informações.



Não quero apenas imagens de telas: quero um aplicativo com botões funcionais, formulários e dados persistentes. Não quero conectar contas bancárias nesta primeira versão.



Crie uma aplicação web adaptada para celular, instalável na tela inicial como um aplicativo. Use português brasileiro em toda a interface.



Comece pela estrutura principal, pela tela inicial e pelo módulo financeiro. Depois, poderemos desenvolver os outros módulos juntos.
